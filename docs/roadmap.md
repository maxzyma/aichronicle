# 建设路线图

目标是让 AI 从业者在遇到新技术时，能够回看它的前身、转折和相关事件。项目入口见 [README](../README.md)。

## 下一阶段：真实样本与内容结构

- 选择一组跨时期、跨组织的真实事件，按[编辑规范](editorial.md)完成人工核实。
- 用主线与至少一条专题线验证共享事件、入选理由和关联关系的表达。
- 根据样本确定事件标识、日期精度、来源、核实记录与时间线引用的数据结构。
- 明确候选材料与正式发布数据的边界。

完成依据：同一批事件能同时支持行业概览和专题回溯，且每个正式条目都能查到核实依据。

## 后续：独立子站

- 在 The Untold 品牌下设计独立阅读入口；复用适用的既有品牌规范与共享交互。
- 实现主线、专题切换、事件详情和来源查看。
- 确定技术栈、部署方式和子域名，再接入发布流程。

完成依据：读者能从一个新事件追溯前事、进入专题，并核查来源。

## 持续维护

- 自动化聚合候选与去重线索，人工决定核实和收录。
- 建立纠错、来源失效处理与后续回看的流程。
- 从同一事件库派生年度回顾、技术沿革与其他专题内容。

完成依据：候选不会绕过人工审核进入公开时间线，维护工作能随日常研究持续进行。
