# 时间轴界面审查

本次是一名评估者的一轮改版前后检查，不是完整可用性或无障碍审计。标准为 Nielsen 十项可用性原则与 WCAG 2.2 AA；启发式判断不等同规范判定，也不宣称整站符合 AA。

基线：2026-09-21，`5dc44bd08b4fa82ef8904743dd0c3ca227a9b1be`；复核对象为此基线上的时间轴改版。实际通过原生 Chrome 无头浏览器打开正式旧版与本地新版，查看桌面及手机截图。下表仅列实际发现的问题，按严重程度排序。

| 位置 | 违反项 | 严重度 | 怎么改 |
| --- | --- | --- | --- |
| Agent 专题筛选后首次点击事件标题 | Nielsen 用户控制与自由：搜索失焦时重复刷新列表，可能打断首次导航；交互复现 | 3：常见筛选路径 × 导航失败 × 需再次点击 | 已修：保留 input 处理，移除重复 change 处理，避免失焦时再次替换节点；同一路径复测通过。 |
| 主线事件日期列与手机事件列表 | 用户要求的时间轴形态未满足；Nielsen 与现实世界匹配的启发式判断 | 2：每次浏览 × 时间关系难扫读 × 持续存在 | 已改：连续轴线、日期节点、年份分段；手机保留轴线。明确节点间距不代表时长。 |
| 主线首屏介绍区及筛选表单 | Nielsen 简洁设计的启发式判断：介绍与筛选挤占事件阅读空间 | 2：每次进入 × 推迟阅读事件 × 持续存在 | 已改：压缩开场，折叠高级筛选，保留直接搜索；手机首屏仍以入口为主，完整首条需向下滚动。 |
| 长列表的年代定位 | Nielsen 识别优于记忆、使用效率的启发式判断 | 2：跨年回顾 × 反复滚动或打开下拉框 × 随内容增加 | 已改：桌面侧边年份索引，手机横向年份选择；筛选状态以 aria-pressed 表达，刷新保留查询参数。 |

交互复核覆盖年份选择、关键词、排序、无结果、重置、刷新恢复、详情导航与浏览器返回；320、390、768、1440 像素宽度未发现页面横向溢出，无新增页面脚本错误。键盘入口实测可到达跳转正文链接，控件保留可见焦点；正文与控件的文字、边界采用更明确的颜色层级。内容、批准指纹和两条时间线成员未改动。

未评估：屏幕阅读器完整播报、真实触屏设备、所有浏览器、强制高对比度、200%／400% 缩放和全量 WCAG 条款。没有访问凭证流程。上述未覆盖项不能推断为通过。
