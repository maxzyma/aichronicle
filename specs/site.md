# 站点规格

Astro 静态生成，默认路径 `/aichronicle/`，支持 `SITE_URL` 和 `SITE_BASE` 迁移到独立域名。共用一份布局、语义色彩、页头页脚与时间线组件；无运行时服务、无用户追踪。

页面包括主线、Agent 专题、事件详情、Agent 综述、关于与编辑方法。搜索条件写入 URL，可分享与刷新保留。窄屏仍可筛选、打开详情和来源；无 JavaScript 时可读全部已发布记录。

正式构建只消费有效人工审核记录；候选详情页不生成。编辑预览使用独立输出目录并带 noindex，不能上传到正式 Pages。没有通过审核的记录时，显示明确的准备中状态，不展示虚构事件或虚构统计。

综述涉及的事件全部通过审核后才展示其正文。代码和内容均可在 GitHub 独立阅读与再利用。
